# muse-playbook
Publicly shared learnings that I've given my Muse based on real life usage for completing various day to day tasks.

## Skills

| Skill | What it does |
|---|---|
| [bland-phone-calls](skills/bland-phone-calls) | Make AI phone calls with Bland.ai: set up a Bland account and API key, place calls, read transcripts, and navigate IVR menus reliably. |

To use a skill, tell your Muse: "Install and use the skill at https://github.com/vumapathy/muse-playbook/tree/main/skills/<skill-name>" — it will guide you through any setup.
