# 2026-09-28 — Phone task lessons (sanitized, public)

Two failed pharmacy IVR calls today (vaccine-appointment cancellation and stock check). No browser-based phone calls today.

## Pharmacy-chain IVRs

1. **Prescription-number gates block non-prescription tasks.** Pharmacy IVRs increasingly require a numeric prescription number before ANY pharmacy interaction, including appointment management. A vaccine-appointment confirmation/scheduling code is NOT a prescription number — do not feed it into the prescription-number prompt; it will be rejected.
2. **Never fabricate an Rx number or confirmation code.** Refuse the prompt and ask for a human. An invented number could attach an action to the wrong prescription.
3. **Caller-ID SMS verification is a hard block for detached AI-agent runs.** The IVR texts a code to the patient's registered phone, and the agent has no way to read it. Attempting anyway wastes ~4 minutes and ~$0.50 per call with zero result. Bail once the gate is identified; only attempt when the user is live and can relay the code in real time.
4. **Voicemail/callback offers from an IVR are a dead end on a detached run.** Unless the transcript shows the message was actually recorded, treat "we'll call you back" as a failure, not progress.
5. **Verify outcomes against the transcript, not the summary.** Automated call summaries can overclaim (e.g. "agreed to leave a voice message") when the transcript shows no message was recorded. Transcripts are ground truth.
6. **Prefer online flows for pharmacy appointment changes.** The online manage-appointment link from the confirmation email succeeded same-day in minutes while two phone attempts failed against structural IVR gates.
7. **Keep the opener short against talkative IVRs.** Long opening lines get talked over and mangled in transcription; one short sentence at a time.

## Cost-per-task note

Two failed IVR calls (~4 min, ~$0.55 each, zero outcomes) vs. one successful online cancellation. Cheap early attempts are still worth it for signal — they exposed the structural gates — but do not retry the same gate without a new channel.
